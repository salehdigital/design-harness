# Design harness (starter)

An opinionated schema for an agent-native design system. Fill each page with records, one Markdown file each.

- **Foundations**: The design system values: the decisions every design is made from.
- **Intelligence**: Context for agents: who does the work, what they may and may not do, and the words and lessons they share.
- **Components**: Built pieces: components, the patterns they combine into, and the screens made of those.

A record is a file with frontmatter (title, slug, description, chips) and a body of plain notes. Copy
`_example.md` in any folder to start one. Point your agent at this folder before it designs.

From Ahmed Saleh, "What is a design harness?" (saleh.digital).
