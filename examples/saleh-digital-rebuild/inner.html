What is a design harness

Design harnesses are specifications written in Markdown that tell AI agents how to recreate a design system. They bridge human intent and machine execution by documenting every design decision--tokens, components, interactions, and principles--in plain language.

Structure

A harness is organized into three sections:

Foundations document the visual language: typography, colors, spacing, motion, materials, themes. These are the atoms of the design system.

Components specify UI elements: chips, buttons, switches, navigation items, covers. Each component has anatomy, states, styling, and usage rules.

Intelligence captures the project's memory: agents (Ada, Dev, Wren, Web), skills (procedures), tools (benches), vocabulary (project-specific terms), and policy (principles like "Detail Over Decoration").

Why harnesses work

Traditional design systems are reference documents. Agents read them but still guess at implementation details. Harnesses are executable specifications. They include exact values, code snippets, and decision rationale.

A harness says: "Chips have 4px padding, 16px height, 8px border-radius, and use var(--dot) at 12% alpha for borders." Not: "Chips are small rounded labels."

Tokens and sliders

Foundation sliders let users tune the feel of the interface without breaking the design. Energy (0--1) adjusts motion speed. Texture (0--1) controls grain and ink filter intensity. Density (0--1) scales spacing.

These sliders modulate token values. For example, --gap calculates as: calc(24px + (.3 - var(--fnd-density)) * 20px). At density 0, gap is 44px (spacious). At density 1, gap is 10px (compact).

Writing a harness

Start by documenting what exists. Measure the live site: hex colors, pixel sizes, font weights, easing curves. Capture the source CSS and component code. Write it down in Markdown with frontmatter (title, slug, status, chips).

Test the harness by asking an agent to rebuild the site using only the harness. If the agent guesses, the harness is incomplete. If the agent asks for clarification, the harness is ambiguous. The goal: an agent can recreate the design closely without peeking at the source.
